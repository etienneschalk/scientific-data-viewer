# Learn more

## Supported formats

| Format                  | Extensions                           |
| ----------------------- | ------------------------------------ |
| NetCDF                  | `.nc`, `.netcdf`, `.nc4`             |
| NASA CDF                | `.cdf`                               |
| HDF5                    | `.h5`, `.hdf5`                       |
| Zarr (folder or ZIP)    | `.zarr` folders, Zarr stores, `.zip` |
| GRIB                    | `.grib`, `.grib2`, `.grb`, `.grb2`   |
| GeoTIFF / COG           | `.tif`, `.tiff`, `.geotiff`          |
| JPEG-2000               | `.jp2`, `.jpeg2000`                  |
| Kerchunk (experimental) | `.kerchunk.json`, `.ref.json`        |

## Useful commands

Open the Command Palette (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>) and type
**Scientific Data Viewer**:

- **Show Settings**: plot defaults, dimension slices, attribute display, the
  Python interpreter...
- **Run Healthcheck**: interpreter, packages and open viewers at a glance.
- **Show Extension Logs**: what the extension and its Python process did.
- **Export Webview Content**: save the open viewer as a self-contained HTML report.
- **Open Getting Started Walkthrough**: come back to this page.
